# Draft release notes — Agent Trust Platform 2.0.0-alpha.1

Status: draft preparation only. No tag, GitHub release, package, or image has
been published. The maintainer must review the exact source SHA after merge.
Maintainer approval and functional/recovery gates remain required. Known third-party
dependency CVEs are accepted for development/alpha; hardening is deferred.
This alpha is not production-hardened. PR #12 is already merged; a merge is not
release approval. See current implementation status and KNOWN_SECURITY_ISSUES.md.

## Included

- Vendor-neutral Agent Trust Platform identity and four compatibility workspaces.
- Namespaced Python domain/provider/API/storage/job contracts.
- PostgreSQL durable records and lease/fenced job ledger.
- Rules-only operation without API keys, explicit optional provider adapters,
  workspace-bound bearer auth, and safety regression tests.
- Runtime settings/Uvicorn fixes, transactional assessment result persistence,
  scoped job idempotency and lease-expiry recovery tests on real PostgreSQL.
- Patched frontend dependency locks with unchanged audit gates and PDF checks.

## Known limitations

Real MCP/OpenAPI discovery, durable authenticated telemetry SDKs, shared
multi-tenant isolation, calibrated model confidence, enforcement gateway, and
proprietary integrations are not part of this alpha.

## Maintainer publication gate

Run the full CI/release-preparation workflow, inspect the manifest checksums,
migration notes, dependency/SBOM output, and review the PR. Then create a
prerelease tag/release manually from the reviewed merge SHA. Never mark this
prerelease as latest.

The workflow runs exact-SHA CI before checksums, now including full-stack browser,
recreation/upgrade/restore, image vulnerability and CycloneDX SBOM gates. All
dependency findings are retained and informational by explicit owner policy.
Scanner execution, inventory and all non-dependency protections still block.
Evidence is retained in CI artifacts for 14 days. See ALPHA_ACCEPTANCE.md and
IMPLEMENTATION_STATUS.md for exact tested sources and unresolved findings.
The checksum manifest still sets `release_ready: false` and creates no tag/release.
