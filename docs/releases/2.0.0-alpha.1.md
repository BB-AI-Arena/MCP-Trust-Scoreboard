# Draft release notes — Agent Trust Platform 2.0.0-alpha.1

Status: draft preparation only. No tag, GitHub release, package, or image has
been published. The maintainer must review the exact source SHA after merge.

## Included

- Vendor-neutral Agent Trust Platform identity and four compatibility workspaces.
- Namespaced Python domain/provider/API/storage/job contracts.
- PostgreSQL durable records and lease/fenced job ledger.
- Rules-only operation without API keys, explicit optional provider adapters,
  workspace-bound bearer auth, and safety regression tests.

## Known limitations

Real MCP/OpenAPI discovery, durable authenticated telemetry SDKs, shared
multi-tenant isolation, calibrated model confidence, enforcement gateway, and
proprietary integrations are not part of this alpha.

## Maintainer publication gate

Run the full CI/release-preparation workflow, inspect the manifest checksums,
migration notes, dependency/SBOM output, and review the PR. Then create a
prerelease tag/release manually from the reviewed merge SHA. Never mark this
prerelease as latest.
